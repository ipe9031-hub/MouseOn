# MouseOn r044 — 자이 디자인 적용판

MouseOn r044 디자인 적용판 — r039/r040/r041/r042/r043에서 적용

패치 로그
- 승인한 시안의 자이 딥 블루와 반투명 흰색 중심 디자인을 적용했습니다. 제목/본문/주요 버튼은 딥 블루, 선택/완료/차량 동선은 헤리티지 블루, 패널은 흰색과 중성 회색으로 통일합니다.
- GS 오렌지 굴착기, 보라색 스카이, 황갈색 롤러, 적색 펌프/크레인 등 장비 구분을 정리했습니다. 명시적인 현장 고위험 색상은 보존하고 위험/삭제는 빨강을 유지합니다.
- 모바일/PC 도구와 설명창·사진 메뉴·연결 상태·확대 도구의 모서리, 그림자, 테두리, 대비를 통일했습니다.
- 타설 차량 동선 화살표와 레미콘은 파란색으로 표시합니다.
- r043 품평회용 수정사항 포함: 모바일 위쪽 작업 설명/바깥 터치 닫기/1.5초 이동, 사진 좌표 고정, 확인 사진 썸네일 유지, 상세사진 ⋯, 숨긴 다중 삭제 메뉴, 타설 전체 동선. r042 중복 정리/장비 주변 배치/클라우드 저장도 포함합니다.
- PMX 실시간 연동 및 원형/부채꼴 반경·새 도형 도구는 미포함입니다. 일반 브라우저의 회의 옆 웍스 로그인 탭 연결은 후속 확인 대상으로 기존 연동 엣지를 유지합니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 닫습니다.
2. ZIP의 MouseOn 폴더 내용을 기존 r039~r043 폴더에 병합·덮어씁니다. data 폴더는 유지합니다.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 모바일 새로고침.
4. 현장 계정에 다시 로그인합니다.

SQL 변경은 없습니다. r043을 먼저 설치하지 않고 바로 적용할 수 있습니다.

직전 품평회용: MouseOn-Patch-r039-to-r043.zip / MouseOn-Full-r043.zip

검증: PC·모바일 주요 동작 15개 통과. r039~r043 병합 결과와 전체 ZIP 일치 확인.
회사 PMX 응답·현장사진·로그인 정보·생성 시안은 ZIP 미포함.
