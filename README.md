# MouseOn 수정 버전 시험용

Windows 10/11 x64용입니다. ZIP을 모두 풀고 `Start-MouseOn-Internet.bat`을 실행합니다.
회사 내부망에서는 `Start-MouseOn.bat`을 사용할 수 있습니다. 주최자가 회의 비밀번호를 지정합니다.
이전 실행 창을 닫고 새 폴더에 압축을 풀어 실행하세요. 기존 `%LOCALAPPDATA%/MouseOn` 데이터를 유지합니다.

## 이번 수정

- 회의 메뉴는 세로 아이콘 모음으로 펼쳐집니다. 선택한 도구가 사진 위 패널에 열리며 사진 크기는 유지됩니다.
- 현장 설정을 작업 등록 위로 이동했습니다. 탑뷰 등록·교체는 현장 설정에서만 합니다.
- 전체화면 버튼은 회의 메뉴 반대편 상단에 있습니다.
- 현장 설정에서 영역을 누르면 별도 지도 편집 화면으로 들어가 이름과 경계를 수정합니다. 객체 목록은 표시하지 않습니다.
- 공유 경계를 움직이면 A가 늘어나는 만큼 이웃 B가 줄어듭니다. 점 추가·삭제·되돌리기·취소, 영역 삭제 후 이웃으로 합치기를 지원합니다.
- 기존 독립 영역이 겹친 경우는 자동 연결하지 않습니다. 필요한 경우 전체 자동 배치 후 조절하세요.
- 개인 화면 확대·구간 확대·이전 보기와 펜 굵기 조절을 추가했습니다. 확대는 다른 참여자의 화면을 바꾸지 않습니다.
- 모바일 참여자 포인터를 제거했습니다. 펜 해제와 지우기 후에는 사진 이동으로 돌아갑니다.
- 제공받은 웍스 진단과 저장 HTML의 일정 제목 태그 `a.sch_title`에 맞춰 수집기를 수정했습니다.

## 시험 순서

1. 회의 메뉴 → 현장 설정에서 기본 탑뷰를 등록하고 동·시설의 이름, 별칭, 영역을 저장합니다.
2. 영역을 눌러 이름·경계·점 편집을 시험하고 현장 설정 백업을 저장합니다.
3. 모바일로 QR에 참여하여 개인 확대와 펜 굵기를 시험합니다.
4. 웍스 메뉴 → 로그인 창 열기 → 직접 로그인 → 해당 캘린더의 하루 보기 → 날짜 지정 → 하루치 읽기 → 미리보기 확인 → 반영합니다.

## 검증과 한계

자동 테스트 37개 통과. ZIP에는 사용자 사진·일정·로그인 프로필을 포함하지 않습니다.
실제 Windows에서의 실행과 수정 수집기의 회사 로그인 화면 읽기는 재확인이 필요합니다.
저장 HTML에 일정 제목 12개가 있음을 확인했지만 실제 계정 자동 수집 성공을 뜻하지는 않습니다.
현재 웍스 기능은 수동 하루치 읽기 시험입니다. 공식 API 자동 동기화는 향후 개발 대상입니다.
주기적 동기화·원본 수정/취소 반영·AI 의미 해석·PMX 연동·자동 간섭 판정은 아직 구현되지 않았습니다.
위치와 작업 분류는 규칙 기반 시험입니다. 원문을 확인하고 반영하세요.

현장 설정과 기본 사진은 회의와 분리해 저장하며 프로그램 폴더를 바꿔도 같은 PC 계정에서 재사용합니다.
세부 사용법과 저장 위치는 ZIP 안 QUICKSTART.txt를 확인하세요.
