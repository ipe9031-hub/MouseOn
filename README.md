# MouseOn r042

MouseOn r042 패치 — r039/r040/r041에서 적용

패치 로그
- 웍스 화면 읽기와 통신 읽기의 식별자가 달라 같은 작업이 두 번 생기는 경우를 정리합니다. 같은 날짜/원문/분류에서 원본이 명확한 경우만 연결하며, 실제 별도 일정과 수동 등록 작업은 유지합니다. 같은 원본 중복은 다음 정상 갱신 때 정리하고 직접 이동한 위치와 작업영역을 우선 보존합니다.
- 상하 작업 해석을 개선했습니다. 스카이는 하부 노출 작업으로 분류하고 로프 등 상부 작업과 비교합니다. 스카이와 지상 작업만으로 상하 경고를 만들지 않습니다.
- 실제 작업영역이 분리되거나 명시 시간이 겹치지 않으면 제외합니다. 동 영역만 있으면 작업영역 확인 필요, 시간이 없으면 시간 확인 필요, 스카이 높이 관계가 불분명하면 작업 높이 확인 필요로 안내합니다. 자정을 넘기는 명시 시간도 비교합니다.
- 경고는 상부/하부 작업명과 확인할 항목만 간단히 표시하고 원문과 판단 근거는 자세히에서 펼칩니다. 같은 원본 작업 쌍의 반복 설명을 줄였습니다. 이는 현장 검토 안내이며 안전 승인 판정이 아닙니다.
- 기존 사진 직접 위치 지정, 자재 반입 대기, 작업영역 드래그, 수동 경계 밖 50px 이동, 사진 전체 펜, 10초 갱신, 클라우드 저장을 유지합니다.
- 기어 왼쪽 다중 선택 버튼으로 아이콘을 선택/해제하고 선택 삭제합니다. 확인 전 취소할 수 있으며, 동일한 웍스 원본은 다음 갱신에서 되살리지 않습니다. 원본 내용이 바뀌면 다시 반영합니다.
- 굴착기/이동식 크레인/스카이/펌프카/롤러 등 지상 장비는 건물 영역 바깥 주변에 자동 표시합니다. 작업영역은 별개로 유지하고 직접 옮긴 위치는 보존합니다. 주변 공간이 없으면 위치 확인으로 남깁니다.
- 위치 이동 모드에서 한 번 옮기면 주변 완료 버튼을 표시하고, 완료하면 일반 모드로 돌아옵니다.
- PMX 실시간 연동은 이번 버전에 포함하지 않았습니다. 자료 구조를 확인했으며 로그인 연결은 후속 작업입니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 닫으세요.
2. ZIP의 MouseOn 폴더 내용을 기존 r039/r040/r041 폴더에 병합·덮어쓰세요. data 폴더는 삭제하지 마세요.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 모바일 새로고침.
4. 현장 계정에 다시 로그인하고 웍스 불러오기/지금 갱신을 눌러 중복과 작업 해석을 갱신하세요.

SQL 변경은 없습니다.

회사 PMX 응답·사진·로그인 정보는 배포 파일에 포함하지 않았습니다.
