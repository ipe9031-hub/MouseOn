# MouseOn 인터넷 참여 시험용

Windows 10/11 x64용 샘플입니다.

1. `MouseOn-Internet-Windows-x64.zip` 파일을 다운로드하고 전부 압축 해제합니다.
2. `Start-MouseOn-Internet.bat`을 실행합니다.
3. PC에서 열린 브라우저에 이름을 입력하고 **원하는 비밀번호(4자 이상)를 정해** 회의를 만듭니다.
4. **참여 링크 · QR**에서 **인터넷 연결됨**을 확인하고 휴대폰에 공유합니다.
5. 휴대폰에서 QR을 스캔하고 같은 비밀번호로 참여합니다. LTE/5G로도 연결하도록 구성되어 있습니다.

실행 창은 계속 열어두세요. 재실행하면 임시 주소가 바뀌며, 기존 회의 비밀번호는 유지됩니다.
Cloudflare 임시 터널을 사용하며 회사 네트워크에서 해당 연결이 허용되어야 합니다.
실제 Windows/LTE 연결은 아직 검증 전입니다. 개발 환경에서 DNS 제한으로 외부 접속을 완료하지 못했습니다.
자동 테스트 10개와 ZIP 무결성 검사는 통과했습니다.
네이버웍스·PMX·AI는 미연동입니다. 현장 사진이나 비밀번호는 포함하지 않았습니다.

파일은 GitHub에서 **Download raw file**로 내려받을 수 있습니다.
다운로드 검증용 SHA256은 `SHA256SUMS.txt`를 확인하세요.

## 탑뷰 중심 화면 / 날짜 선택

상단 소개와 우측 고정 목록을 없애고 왼쪽 ☰ 메뉴로 이동했습니다.
제목은 명일 작업사항 (날짜)이며 한국 시간 기준 다음 날을 표시하고 일요일은 건너뜁니다.
금요일은 토·일을 함께 표시하고 다음 주 월요일도 선택할 수 있습니다.
모바일을 포함해 날짜는 각자 자유롭게 선택하고 작업 등록 날짜도 지정합니다.
작업 등록에서 지점·영역·방향 동선을 찍고 저장할 수 있습니다.
영역과 동선은 아이콘 hover/tap 시 표시하며 클릭하면 고정, 빈 곳을 누르면 해제합니다.
동/부대시설 기본 영역의 영구 설정은 이번 시험 버전에 아직 포함하지 않았습니다.

## 장비 그림·사진 조작·작업 삭제

날짜 선택은 회의 도구 안으로 이동했습니다. 문제 사진 명칭은 상세 사진으로 바꿨습니다.
타워크레인/이동식 크레인/타설/굴착기/지게차/레미콘/덤프를 통일된 SVG 아이콘으로 표시합니다.
타워크레인은 순번·순서 변경 버튼을 표시하지 않습니다.
사진 이동·크기 도구에서 휠 확대/축소, 드래그 이동, 파란 모서리 드래그로 크기를 조절합니다.
사진 원본은 그대로 보존하고 보기만 바꿉니다. 화면 맞춤으로 초기화할 수 있습니다.
작업 관리 목록이나 선택한 아이콘의 작업 삭제 버튼에서 삭제할 수 있습니다. 확인 후 참여자 모두에게 반영합니다.
