# MouseOn r036 — 캘린더 선택 대기에서 멈추는 자동 배치 수정

- r031·r032·r033·r034·r035 사용자는 **`MouseOn-Patch-r031-to-r036.zip` 하나만 적용**하세요.
- 신규 설치 또는 다른 버전은 `MouseOn-Full-r036.zip`을 받으세요.

## 반드시 실행기를 다시 열어주세요

1. **MouseOn 실행 창(검은 창)과 연동 엣지를 모두 종료**하고 기존 폴더를 백업하세요.
2. ZIP의 MouseOn 내용물을 기존 MouseOn 폴더 안에 병합·덮어쓰세요. **data 폴더는 유지하세요.**
3. `Start-MouseOn-Internet.bat`으로 다시 실행하고 PC Ctrl+F5, 모바일 새로고침을 해주세요.
4. 현장 설정 → 웍스에서 작업 날짜를 확인하고 불러오기를 한 번 누르세요. 캘린더를 추가로 고르는 단계에서 멈추지 않습니다.

기존 실행기가 켜져 있으면 새 코드가 적용되지 않습니다. r036에서는 이전 연동 실행기를 감지해 재실행 안내를 표시합니다. SQL 변경은 없습니다.

## 수정 내용

- 여러 캘린더를 읽은 뒤 ‘현장 캘린더를 선택해주세요’에서 멈추던 흐름을 수정했습니다. 현재 조회 응답의 현장 작업 분류 1~6(타설·갱폼·고위험·장비·비정상·자재상하차)을 한 묶음으로 자동 적용합니다. 회의·행사·점검 분류와 분류되지 않은 개인 일정은 이 묶음에 임의로 포함하지 않습니다.
- 묶음으로 읽어도 원래 캘린더·일정 ID를 유지하며, 조회 범위의 향후 작업도 함께 보관·갱신합니다. 화면과 ‘읽은 일정·지도 표시·위치 확인’ 개수는 선택한 날짜 기준입니다.
- 상세사진을 보고 있을 때 사용자가 불러오기를 실행하면 메인 전경으로 돌아가 배치 결과를 볼 수 있게 합니다. 백그라운드 갱신은 보고 있는 화면을 바꾸지 않습니다.
- r035의 로그인된 캘린더 화면 읽기와 날짜 이동도 유지합니다. 화면 방식은 로드된 해당 날짜 일정만 확인하며, 다른 날짜의 기존 작업을 지우지 않습니다.

검사 34개 통과. 제공된 실제 일정 응답의 **2026-11-19 데이터**를 실제 실행기·브라우저 도구를 통해 읽어, 캘린더 선택 없이 작업 1개가 해당 동의 지도 아이콘으로 표시되는 것을 확인했습니다. 그 날짜의 회의 일정은 제외됐습니다. 이전 실행기 감지, 화면 읽기, 자동 저장·보관기간·영역·사진·배율 기능도 검증했습니다. 실제 회사 로그인 세션은 이 작업 환경에서 접근할 수 없으므로 적용 후 실수집 결과 확인이 필요합니다.

# MouseOn r035 — 웍스 불러오기와 화면 읽기 연결

## 적용 순서

1. **실행 창(검은 창)과 연동용 엣지를 모두 닫고** 기존 폴더를 백업하세요.
2. ZIP의 MouseOn 내용물을 기존 MouseOn 폴더 안에 병합·덮어쓰세요. **data 폴더는 삭제하지 마세요.**

## 수정 내용

- 기존 불러오기 버튼에 로그인된 캘린더 화면 읽기를 연결했습니다. 통신 응답에만 의존하지 않으며, 화면에서 읽은 작업도 같은 해석·자동 배치·저장 경로로 반영합니다. 별도 선택 도구나 JSON 저장·업로드가 필요하지 않습니다.
- 캘린더 날짜가 다르면 캘린더 자체 날짜 버튼으로 맞춘 뒤 해당 날짜의 작업 제목을 읽습니다. 날짜가 확인되지 않은 화면을 다른 날짜 일정으로 등록하지 않습니다. 일정 설정·목록 탭이 함께 열려 있어도 메인 일정 탭을 우선 사용합니다.
- 결과는 **읽은 일정 N개 · 지도 표시 N개 · 위치 확인 N개**로 표시합니다. 위치를 모르는 작업만 위치 확인에 남습니다. 같은 화면을 반복해 읽어도 같은 항목을 중복 등록하지 않습니다.
- 화면 읽기도 연결 후 주기적으로 다시 읽어 반영합니다. 실행기와 로그인된 연동 엣지 창은 계속 열어두세요. 로그인 만료 시 수집을 중단합니다.
- 화면 방식은 현재 로드된 선택 날짜의 일정만 확인합니다. 다른 날짜 작업은 유지하지만, 화면에 없는 다른 날의 수정·취소를 확인했다고 표시하지 않습니다.
- 과거 날짜를 시험할 때 클라우드 보관기간 정리가 방금 읽은 작업까지 화면에서 지우지 않도록 분리했습니다. 클라우드 저장 사본은 오늘·어제·향후 작업을 유지하고 더 오래된 작업을 제외합니다. 탑뷰·영역·사진은 이 규칙으로 삭제하지 않습니다.

검사 30개 통과. 제공된 캘린더 HTML에서 실제 실행기·브라우저 도구로 일정 12개를 읽고, 불러오기 한 번으로 지도에 등록되는 흐름을 확인했습니다. 원본 HTML의 스크립트 실행과 외부 자원 요청을 차단하고 데이터로만 사용했습니다. 네트워크 응답이 없거나 관찰 기능이 실패한 조건, 날짜 이동 후 읽기, 재수집·중복 방지, 기존 클라우드 저장과 영역·사진 기능도 검사했습니다. 실제 회사 로그인 세션은 이 작업 환경에서 접근할 수 없으므로 적용 후 사용자 환경의 실수집 결과 확인이 필요합니다.
r031·r032·r033·r034 각각에 이 패치를 적용한 파일 구성이 전체 ZIP과 정확히 일치함을 확인했습니다. 사용자 사진·일정 원문·데이터·로그인 세션은 ZIP에 포함하지 않습니다.

공유 시 같은 회의 QR·참여 링크로 참가하면 하나의 서버 상태를 함께 사용합니다. 같은 작업을 동시에 이동하면 마지막 변경이 반영됩니다. 서로 다른 PC에서 같은 현장 저장 계정으로 저장하다 충돌하면 자동 저장을 멈추며 다른 PC 내용을 덮어쓰지 않습니다.

# MouseOn r034 — 영역 이동·점 붙임 · 웍스 즉시 배치 · 자동 저장

- r031·r032·r033 사용자는 **`MouseOn-Patch-r031-to-r034.zip` 하나만 적용**하세요. 중간 패치를 설치할 필요가 없습니다.

## 영역 조작

- 점은 가까운 기존 점에 붙고 더 당기면 풀립니다. 선에 붙으면 선을 따라 이동합니다. 기준은 사진 확대와 무관한 화면 픽셀입니다.
- 사용자가 만든 가까운 점·작은 모서리·직선 중간 점을 거리로 합치거나 삭제하지 않습니다. 수치 연산에서 같은 좌표가 겹친 경우만 중복 처리를 합니다. 같은 위치 근처를 다시 누르면 불필요한 새 점 대신 기존 점을 선택합니다.
- 영역 전체를 끌 때는 모든 점과 이름에 같은 이동량을 적용해 모양을 보존합니다. 이웃 영역은 자리를 내주며, 떠난 자리는 다시 채워집니다. 다른 영역 안에 독립 영역을 넣는 형태도 지원합니다. 다른 영역을 완전히 없애는 편집은 거부합니다.
- 아웃라인 바깥 화면 기준 10px를 넘으면 사진 위 그리기·작업/사진 배치·내부 영역 편집 입력을 무시합니다. 메뉴·화면 이동·확대축소와 아웃라인 자체 편집은 계속 사용할 수 있습니다.

## 일정과 저장

- 웍스 가져오기를 현장 설정 맨 위로 옮겼습니다.
- 불러오기를 누르면 이미 읽은 선택 캘린더 데이터를 즉시 해석·배치하고, 재조회 결과로 갱신합니다. 상태 확인 중 누른 버튼이 무시되는 문제와 부가 요청 때문에 일정 수집이 조기에 중단되는 문제를 수정했습니다. 위치를 찾지 못한 작업만 위치 확인에 남깁니다.
- 현재 웍스 조회 응답에 포함된 선택 날짜 이후 일정도 함께 보관·갱신합니다. 조회되지 않은 다른 달이나 다른 캘린더까지 임의로 수집하지 않습니다. 화면에는 선택한 작업 날짜의 작업을 표시합니다.
- **현장 설정 → 영역에서 저장 계정에 로그인**하세요. 기존 공유 현장은 먼저 불러오거나 저장하면 이후 변경을 자동 저장합니다. 새 현장은 웍스 반영 시 저장 항목을 만듭니다. 회의를 새로 열어도 연결한 현장의 향후 작업을 이어받습니다.

자동 수집은 **실행기와 로그인된 엣지 창**, 자동 저장은 **로그인된 현장 저장 계정과 실행기**가 필요합니다. PC를 꺼둔 동안에는 수집·저장·정리를 실행하지 않으며 다음 실행·로그인 때 로컬 변경과 정리를 이어서 저장합니다. 저장 계정 로그인은 실행기 재시작 후 다시 필요합니다. 로그인 토큰·비밀번호는 ZIP이나 자동 저장 연결 파일에 넣지 않습니다. 웍스 로그인은 기존 별도 엣지 프로필을 사용합니다.

- 사진 위에 뜨는 도구로 외곽선 점을 추가·삭제·이동합니다. 사진 크기는 그대로입니다.

- 작업 저장·취소 후 지도 화면으로 돌아갑니다. 작업 설명이 세로 한 글자씩 꺾이던 문제를 수정했습니다.

- 메인 화면의 이전 보기·전체 보기 버튼을 제거했습니다. 주최자 PC에서 기존 그림이 있을 때 펜으로 짧게 누르면 주변 메뉴에 지우기가 표시됩니다.
