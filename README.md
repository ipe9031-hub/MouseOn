# MouseOn 영역 설정·모바일 조작 수정 시험판

Windows 10/11 x64용입니다. 최근 a95d9b5 버전을 사용했다면 `MouseOn-Patch-from-a95d9b5.zip`을 받으세요.
이전 버전이거나 잘 모르겠으면 `MouseOn-Patch-from-0b33141.zip` 누적 패치 또는 전체 `MouseOn-Internet-Windows-x64.zip`을 사용하세요.
`MouseOn-Design-Patch-from-a5c6b3d.zip`도 이번 내용까지 갱신했습니다.

실행 창과 웍스 연동 브라우저를 닫고 기존 폴더를 백업하세요. 패치 ZIP 안 MouseOn의 내용물을 기존 MouseOn 폴더 안에 병합·덮어쓴 뒤 다시 실행합니다.
PC는 Ctrl+F5, 모바일은 새로고침하세요. 기존 data 폴더와 %LOCALAPPDATA%/MouseOn은 삭제하지 마세요.
처음 사용하는 경우 전체 ZIP을 풀고 Start-MouseOn-Internet.bat을 실행합니다.

## 이번 변경

- 사진 위에 뜨는 도구로 외곽선 점을 추가·삭제·이동합니다. 사진 크기는 그대로입니다.
- 점으로 별도 건물 영역을 그려 완성하면 주변 영역이 공간을 내줍니다. 건물 영역은 자동 영역 추가 후에도 유지합니다.
- 영역을 누른 곳 가까이 이름 입력창이 뜨며 이름과 모양을 함께 수정합니다. 현장 설정의 제목은 ‘영역’입니다.
- 사진을 짧게 누르면 그리기·작업 등록을 고릅니다. 작업은 누른 위치에 기본 등록하고 영역·동선은 필요할 때 지정합니다.
- 작업 저장·취소 후 지도 화면으로 돌아갑니다. 작업 설명이 세로 한 글자씩 꺾이던 문제를 수정했습니다.
- 모바일은 100%에서 사진 위치를 고정합니다. 확대했을 때 사진 범위 안에서 이동하며 인터페이스 크기는 유지합니다.
- 현장 설정은 오른쪽 위 스프로킷 아이콘 하나로 표시하고 웍스 가져오기를 그 안으로 옮겼습니다.
- 메인 화면의 이전 보기·전체 보기 버튼을 제거했습니다. 주최자 PC에서 기존 그림이 있을 때 펜으로 짧게 누르면 주변 메뉴에 지우기가 표시됩니다.
- QR 아이콘 모양 교체와 전체 회의 도구(…) 제거는 이번 변경에 포함하지 않았습니다.

## 현장 저장과 웍스 시험

현장 설정에서 탑뷰·외곽선·영역 이름과 경계·글꼴·고위험 종류를 저장하고 현장 백업을 따로 보관하세요.
기존 사진·현장 설정·로그인 프로필은 패치에 포함하지 않습니다.

웍스 화면 읽기와 통신 데이터 자동 수집 시험을 유지합니다. 직접 전용 브라우저에 로그인하며 비밀번호나 쿠키를 앱에 입력하지 않습니다.
통신 구조 진단은 건수·필드 이름 등 구조 정보만 저장합니다. 실제 회사 통신 응답과 자동 수집은 검증 중입니다.
캘린더 분류별 배치 제외(예: 7. 회의, 행사, 대내외점검)와 여러 동 문장 해석은 후속 개발입니다.
현재 위치·분류는 규칙 기반 시험이며 AI 의미 해석·PMX·자동 간섭 판정·완전한 반복 일정 동기화는 지원하지 않습니다.

## 검증

Chromium 자동 테스트 49개 통과. 외곽선 점 편집·건물 영역 공간 비우기·설정 저장·모바일 확대와 작업 등록·공유 그림 및 지우기 권한을 확인했습니다.
누적 패치를 기존 일곱 버전에 적용한 결과가 전체 ZIP의 파일들과 일치함을 검증했습니다.
실제 Windows와 회사 캘린더 동작은 사용자 PC에서 최종 확인이 필요합니다.
