# MouseOn 수정 시험 버전

Windows 10/11 x64용입니다. 처음 사용하거나 기존 버전을 모르면 전체 ZIP을 모두 풀고 Start-MouseOn-Internet.bat을 실행합니다.
기존 버전 0b33141, a01b4b2, 1d7fe1c, 32574a6, e4f27d7 사용자는 MouseOn-Patch-from-0b33141.zip 누적 패치를 사용할 수 있습니다.
실행 창과 연동 창을 닫고 프로그램 폴더를 백업한 뒤 패치 ZIP의 MouseOn 폴더 안 내용을 기존 MouseOn 폴더 안에 병합·덮어쓰기합니다.
다시 실행하고 PC·모바일 브라우저를 새로고침하세요. PC는 필요하면 Ctrl+F5를 누릅니다.
%LOCALAPPDATA%/MouseOn 데이터 폴더는 그대로 보관합니다. 사진·현장 설정·로그인 프로필은 패치에 포함하지 않습니다.

## 이번 수정

- 사진을 짧게 누르면 펜 입력, 기본 상태에서 누르고 끌면 사진 이동. 입력 취소는 기존 그림을 남기고 이동 상태로 복귀합니다.
- 펜 입력 중에도 두 손가락으로 사진 이동·확대/축소할 수 있습니다. PC는 스페이스바+드래그를 지원합니다.
- 펜 기본 굵기는 5, PC 그림 hover는 작성자 표시, 참여·지우기는 이름을 포함한 알림을 표시합니다.
- 그림이 생기면 주최자 PC에만 지우기를 표시하며 확인창 없이 공유 그림 전체를 지웁니다.
- 가리키기·사진 이동 버튼·그림 되돌리기·모바일 전체화면은 제거했습니다. 모바일은 전경 전체가 보이는 100%로 시작하며 그 아래로 축소되지 않습니다.
- 외곽선 → 영역 나누기 → 이름·배치 확인의 마법사를 추가했습니다. 외곽선을 점으로 지정한 뒤 영역을 추가하면 주변 영역이 자리를 내주며 즉시 나뉩니다.
- 영역 이름은 클릭한 곳 가까이 뜨는 입력창에서 수정합니다. 별칭과 번호 목록은 표시하지 않습니다.
- 영역 편집 도구는 세로 아이콘 모음으로 정리했습니다. 경계 점 추가·삭제·되돌리기는 유지합니다.
- 현장 설정에서 기기 기본/나눔고딕 글꼴을 선택하고 고위험 작업 종류를 추가·삭제합니다. 공통 한글 글꼴 파일을 함께 제공합니다.
- 픽토그램 모양을 유지하면서 작업별 색상을 구분하고 카드·버튼 테두리를 줄였습니다.
- 탑뷰·영역 경계·이름·외곽선·글꼴·고위험 작업 종류를 저장하고 백업합니다.

## API 앱 등록 없는 일정 데이터 자동 수집 시험

이 버전은 로그인한 브라우저가 받는 JSON 일정 응답을 수집합니다. 화면 글자나 좌표는 읽지 않습니다.

1. 웍스 일정 연동 → 회사·엣지 → 로그인 창 열기 → 직접 로그인하고 현장 캘린더와 조회 기간을 선택합니다.
2. 데이터 연결을 누르면 페이지가 다시 로드되며 일정 데이터 응답을 찾습니다.
3. 확인된 현장 캘린더와 날짜를 선택하고 자동 수집을 시작합니다. 체크하지 않으면 미리보기만 갱신합니다.
4. 원문과 범위를 확인한 뒤 새 일정·수정을 이 회의에 자동 반영을 체크하고 시작하면 지도에 반영합니다.

기본 1분 간격이며 30초·2분·5분도 선택할 수 있습니다. 브라우저는 최소화해도 되지만 닫으면 중단됩니다.
같은 PC의 전용 로그인 프로필을 재사용합니다. 프로그램 재실행 후에는 수집 범위를 다시 선택해야 합니다.
일정 ID로 중복을 막고 내용 수정을 갱신합니다. 수동 배치 위치는 보존하며 위치 미확인 작업은 확인 대기로 저장합니다.
명시된 취소는 확인 표시를 붙입니다. 조회에서 빠졌다는 이유만으로 작업을 삭제하지 않습니다.

## 검증과 한계

자동 테스트 46개 통과. 경계 고정과 모바일 전체 보기의 추가 검증도 통과했습니다. 실제 Chromium의 모의 일정 통신으로 자동 재조회·수정·로그인 만료를 검증하고,
주최자 화면에서 자동 반영·수동 위치 유지·취소 표시·중지·권한 제한을 시험했습니다.
누적 패치를 기존 여섯 버전에 적용한 결과가 전체 ZIP의 모든 파일과 일치하는 것을 검증했습니다.

실제 회사 계정의 응답 구조는 아직 검증 전입니다. 캘린더가 확인되지 않으면 통신 구조 진단 저장 파일을 전달해주세요.
진단에는 필드 이름과 건수만 포함하며 일정 원문·비밀번호·쿠키·인증 헤더·URL은 포함하지 않습니다.
현재 시험은 응답에 포함된 일정의 시작일 기준입니다. 조회에서 사라진 일정의 삭제, 반복 예외·다일 일정의 완전 동기화,
비밀번호 자동 입력 로그인, 공식 API·AI 의미 해석·PMX·자동 간섭 판정은 아직 지원하지 않습니다.
일정 위치·작업 분류는 규칙 기반 시험입니다. 실제 Windows와 회사 계정에서 원문과 배치를 확인해주세요.
