# MouseOn r043 — 품평회용

MouseOn r043 품평회용 패치 — r039/r040/r041/r042에서 적용

패치 로그
- 모바일 작업 설명을 아이콘 위에 표시하고, 다른 곳을 터치하면 닫습니다. 짧은 터치는 확인, 약 1.5초 길게 누르면 진동 후 위치 이동입니다.
- 지도 작업 아이콘의 최초 분산 위치를 사진 좌표에 유지합니다. 이동/확대/화면 크기 변경 때 화면 안으로 따라오며 재배치하지 않습니다. 직접 옮긴 위치는 그대로 표시합니다.
- 상하 확인 느낌표의 충돌 회피 범위를 늘리고 위치를 유지하며, 다른 곳을 누르면 설명을 닫습니다. 삼각형 작업 아이콘과 원형 상하 확인 표시는 서로 다른 의미를 유지합니다.
- 사진 썸네일을 날짜 필터와 무관하게 PC/모바일 탑뷰에 표시합니다. 확인 완료 뒤에도 핀과 썸네일은 유지하고 미확인 목록에서만 제외합니다. 사진/지도 표시를 직접 삭제할 때만 사라집니다.
- 상세사진의 긴 버튼 목록은 ⋯ 안으로 넣고 설정 기어를 숨깁니다. 사진 복귀 버튼은 작게 표시합니다.
- 상단 다중 삭제 버튼은 작업 등록의 작업 관리 메뉴 안으로 이동했습니다. 캘린더 선택창은 기본 화면에서 숨겼습니다.
- 타설 차량 동선은 펌프카뿐 아니라 굴착기/도로 타설 등 타설 전체에서 지정할 수 있습니다. 화살표와 레미콘, 이전/완료/취소, 호버/터치 표시를 유지합니다.
- r042의 중복 정리·상하 검토·주변 장비 배치·삭제 유지·클라우드 저장 포함.
- PMX 연동과 GS/자이 디자인 개편은 이번 ZIP에 포함하지 않았습니다. 일반 브라우저 회의 창 옆 로그인 탭 연결도 후속 확인 대상이며 기존 연동 엣지는 유지합니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 닫습니다.
2. ZIP의 MouseOn 폴더 내용을 기존 r039/r040/r041/r042 폴더에 병합·덮어씁니다. data 폴더는 유지합니다.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 모바일 새로고침.
4. 현장 계정에 다시 로그인합니다.

SQL 변경은 없습니다.

회사 PMX 응답·현장사진·로그인 정보·디자인 시안은 ZIP에 포함하지 않았습니다.
