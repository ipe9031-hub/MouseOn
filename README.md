# MouseOn r048 — 자유 위치 이동·모바일 아이콘 크기 고정

MouseOn r048 — 자유 위치 이동·모바일 아이콘 크기 고정
r039~r047에서 바로 적용

패치 로그
- 모든 작업 아이콘을 사진 안 어디든 직접 옮길 수 있습니다. 동 영역/50px 이동 제한을 제거했습니다.
- 직접 옮긴 좌표는 PC/모바일이 함께 사용하고 웍스 갱신 때 동 경계로 되돌리지 않습니다. 작업영역·상하 판단은 아이콘과 독립적으로 유지합니다.
- 크레인은 최초 자동 배치 시 건물 바깥에 배치합니다(타워크레인 포함). 예전 자동 배치는 웍스를 다시 갱신하면 새 규칙을 적용하며 수동 위치는 유지합니다.
- 모바일에서 확대해도 아이콘·설명 글씨는 커지지 않고 화면 기준 크기를 유지합니다. 사진과 표시 위치만 확대합니다.
- r047 공유 좌표와 r046 혼합 심볼, r045 사진 이동/경고 숨김·복원/위치 해제 및 기존 기능 포함. PMX는 미포함입니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 종료합니다.
2. ZIP의 MouseOn 폴더 내용을 기존 r039~r047 폴더에 병합·덮어씁니다. data 폴더는 유지하세요.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 참여 휴대폰도 모두 새로고침합니다.
4. 현장 계정 로그인 및 웍스 지금 갱신. SQL 변경은 없습니다.

PMX 미포함. 공유 표시 좌표/확대 크기/자유 이동과 초기 크레인 외부 배치를 검증하고 r039~r047 병합 결과와 전체 ZIP 일치를 확인했습니다.
