# MouseOn r050

MouseOn r050 패치 로그
r039~r049에서 바로 적용

- 작업영역: 사각형에 원형, 원뿔형(60도 부채꼴), 화살표 추가. 드래그로 크기·방향 지정, 이전/완료/취소 지원. 실제 지정 영역은 공유·클라우드 저장 및 상하 작업 겹침 판단에 반영합니다.
- 같은 원본 일정의 작업을 마우스/터치로 선택하면 파란 테두리로 함께 강조합니다. 제목만 같은 다른 일정은 묶지 않습니다.
- 작업 아이콘 동작 메뉴에 진행 순서 입력(1~999)을 추가했습니다. 비워 저장하면 해제하며 같은 원본 내 중복 번호는 막습니다. 순서는 실제 작업 시간이나 안전 확인을 대신하지 않습니다.
- 기존 장비 심볼·단색 타일 디자인을 유지하고 도장/방수/설치 등 작업내용별 배경색을 추가했습니다. 검정/흰색 심볼은 대비에 맞춰 적용합니다.
- 포장 준비는 굴착기, 실제 포장은 롤러로 구분합니다. 포장 반입 동선을 그리면 덤프트럭을 표시하며 콘크리트·투수콘 타설은 레미콘을 유지합니다.
- PMX: 현장코드/날짜 확인보다 로그인 탭을 먼저 열도록 수정했습니다. 실행기 연결 준비 순서를 보강하고 미연결·이전 실행기 안내를 추가했습니다.
- PMX 등록 확인과 문서 연결 기능 포함. 실제 회사 계정의 인증/조회 호환성은 현장 PC 확인 전입니다. O는 연결한 문서의 등록 확인이며 승인·안전 판정이 아닙니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 종료합니다.
2. ZIP의 MouseOn 폴더 내용을 기존 폴더에 병합·덮어씁니다. data 폴더는 유지하세요.
3. Start-MouseOn-Internet.bat를 실행하고 PC Ctrl+F5, 참여 모바일도 새로고침합니다.
4. PMX 로그인/조회 방법은 PMX-QUICKSTART.txt를 참고하세요.
SQL 변경 없음.

검증: PC·모바일 작업영역/그룹 강조/진행 순서, PMX 로그인 탭 실제 브라우저 시작 및 모의 응답 조회·문서 연결, 공유 위치·확대·사진·경고 등 25개 테스트 통과. 실제 회사 인증/조회는 현장 PC 확인 전입니다. r039~r049 패치 덮어쓰기 결과와 최종 전체 ZIP 일치 확인.
