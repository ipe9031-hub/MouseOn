# MouseOn r047 — PC·모바일 작업 위치 통일

MouseOn r047 — PC·모바일 작업 위치 통일
r039~r046에서 바로 적용

패치 로그
- PC와 모바일이 화면마다 겹침 회피 위치를 따로 계산하여 작업 아이콘이 다른 곳에 보이던 문제를 수정했습니다.
- 서버에서 정한 사진 기준 표시 좌표를 함께 저장·전달하므로 PC/모바일의 같은 작업이 같은 지도 위치를 가리킵니다. 화면 크기·이동·확대에 따라 재배치하지 않습니다.
- 기존 위치를 먼저 확보하고 새 작업만 분산합니다. 수동 이동은 지정 좌표 그대로 공유하고, 위치 해제 시 공유 표시 좌표도 해제합니다.
- 공유 표시 좌표는 클라우드 사본에도 포함됩니다. 실제 작업영역 및 상하 판단 기준은 별도로 유지합니다.
- r046 색상 배경+검정/흰색 심볼과 r045 기능 포함. PMX는 미포함입니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 종료합니다.
2. ZIP의 MouseOn 폴더 내용을 기존 r039~r046 폴더에 병합·덮어씁니다. data 폴더는 유지하세요.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 참여 휴대폰도 모두 새로고침합니다.
4. 현장 계정에 다시 로그인합니다. SQL 변경은 없습니다.

검증: PC/휴대폰 동시 연결의 사진 좌표 일치, 확대/이동/리사이즈/새 작업/수동 이동/클라우드 표시 좌표 보관. r039~r046 덮어쓰기와 전체 ZIP 일치 확인.
