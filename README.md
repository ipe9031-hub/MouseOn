# MouseOn r045 — 사진 위치·검토 상태·갤럭시 화면 개선

MouseOn r045 — 사진 위치·검토 상태·갤럭시 화면 개선
r039/r040/r041/r042/r043/r044에서 바로 적용

패치 로그
- 사진 썸네일에 사진 보기/위치 이동 메뉴를 추가했습니다. 핀과 연결선을 클릭/드래그로 옮기고 주변의 완료/취소로 저장합니다. 모바일은 1.5초 길게 눌러 이동을 시작합니다. 다른 참여자가 먼저 바꾼 좌표를 덮어쓰지 않도록 비교합니다. 사진 내용·확인 상태는 유지합니다.
- 상하 작업 설명에서 이 경고 숨기기를 지원합니다. 같은 내용의 자동 갱신에는 다시 뜨지 않고, 관련 작업·작업영역이 바뀌면 재표시합니다. 작업 관리 > 숨긴 상하 경고에서 복원합니다. 숨김은 안전 확인 완료와 별개입니다.
- 위치 해제로 작업을 위치 확인 대기에 되돌릴 수 있습니다. 내용은 보존하고 연결된 영역·동선은 확인 후 정리합니다. 재가져오기·갱신에도 대기 상태를 유지하며 직접 새 위치를 찍으면 배치를 재개합니다.
- 갤럭시 등 모바일의 버튼·제목·확대 도구 크기와 터치 영역을 보완했습니다. 시스템 다크 선호에서도 밝은 앱 팔레트와 진한 글씨를 유지하도록 설정했습니다. 삼성 인터넷 고유의 강제 야간모드는 실기기 확인이 필요합니다.
- 사진 위치·경고 숨김·위치 확인 상태는 기존 실시간 공유 및 클라우드 저장에 포함됩니다.
- 새 작업이 기존 고정 아이콘 자리에 겹쳐 들어오는 경우를 수정했습니다. 기존 핀의 자리를 먼저 확보하고 새 핀만 분산합니다.
- r044 자이 디자인 및 기존 기능 포함. 새 색상 배경 작업 아이콘은 비교 시안만 제공하며 사용자 선택 전에는 제품에 적용하지 않았습니다.
- PMX 및 신규 원형/부채꼴 반경 도구는 미포함입니다.

적용 방법
1. 검은 실행창과 연동 엣지를 모두 닫으세요.
2. ZIP의 MouseOn 폴더 내용을 기존 r039~r044 폴더에 병합·덮어쓰세요. data 폴더는 유지하세요.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 모바일 새로고침.
4. 현장 계정에 다시 로그인하세요.

SQL 변경은 없습니다.

검증: 사진 이동/취소/동시 수정 충돌, 경고 숨김/복원/변경 시 재표시, 위치 해제/재갱신, 클라우드 사본, 모바일 다크 선호, 기존 고정 아이콘 겹침 수정 후 재검증. r039~r044 병합 결과와 전체 ZIP 일치 확인.
작업 아이콘의 색상 배경 시안은 별도 검토하며 사용자 선택 전 제품에는 적용하지 않았습니다. 회사 PMX 응답·현장사진·로그인 정보·생성 시안은 ZIP 미포함입니다.
