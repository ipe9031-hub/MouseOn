# MouseOn r049 — PMX 연결 검증용 준비판

MouseOn r049 PMX 연결 검증용 준비판
r039~r048에서 바로 적용

주의: 실제 회사 계정의 인증/조회 호환성은 현장 PC에서 확인 전입니다. 일반 회의용 r048을 별도 제공합니다.

패치 로그
- 현장 설정에 PMX 등록 확인을 추가했습니다. 현장코드/작업 날짜 입력 후 연동 엣지 PMX 탭에서 직접 로그인하고 조회합니다. 연결 후 기본 1분마다 확인합니다.
- 작업 설명에 PTW와 위험성평가의 O/X/?를 간단히 표시합니다. 관련 문서 추천/검색에서 사용자가 연결할 수 있습니다. 제목만으로 등록됐다고 자동 확정하지 않습니다.
- O는 연결한 관련 문서의 등록 확인, X는 사용자가 관련 문서 없음으로 확인, ?는 미조회/로그인/날짜/변경/유효기간 확인 필요입니다. 승인·유효 허가·안전 판정이 아닙니다.
- 로그인/조회 실패를 미등록 X로 표시하지 않습니다. PTW 후보는 최근 90일 내 시작 문서 중 해당 작업일 포함 건입니다.
- 확인한 작업/문서 연결 기록은 기존 현장 클라우드에 보관합니다. 브라우저 인증 정보나 전체 사내 응답을 클라우드/ZIP에 넣지 않습니다.
- r048 자유 이동·아이콘 크기 고정 및 r047 PC·모바일 공유 표시 좌표와 r046 색상 배경 아이콘, r045 기능 포함.

적용 방법
1. 검은 실행창과 연동 엣지를 종료합니다.
2. ZIP의 MouseOn 폴더 내용을 기존 r039~r048 폴더에 병합·덮어씁니다. data 폴더는 유지하세요.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 참여 모바일도 모두 새로고침합니다.
4. 현장 계정에 다시 로그인하고, PMX-QUICKSTART.txt 안내에 따라 회사 PMX에서 로그인/조회합니다.
5. 회사 접속이 안 되면 PMX 표시는 ?로 유지하고 r048을 일반 회의용으로 사용할 수 있습니다.
SQL 변경은 없습니다.

검증: 로그인 대기/고정 조회 API/동일 브라우저 인증/문서 후보 연결/조회 실패/클라우드 연결 기록 및 기존 공유 좌표·자유 이동·크기 고정 등 14개 테스트 통과. 실제 회사 계정의 인증 및 조회 호환성은 현장 PC 확인 전입니다. r039~r048 덮어쓰기와 전체 ZIP 일치 확인.

PMX 원본 등록·수정·삭제는 하지 않습니다. 직원 ID·연락처·인증 헤더 원문 및 실제 사내 응답은 배포 파일에 포함하지 않습니다.
