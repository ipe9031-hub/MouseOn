# MouseOn 다음 버전 시험용

Windows 10/11 x64용입니다. ZIP을 모두 풀고 `Start-MouseOn-Internet.bat`을 실행합니다.
회사 내부망에서만 쓰려면 `Start-MouseOn.bat`을 사용합니다. 주최자가 화면에서 회의 비밀번호를 지정합니다.

## 먼저 시험할 순서

1. 탑뷰 올리기 → 회의 도구의 최초 현장 설정에서 동·시설 이름, 별칭과 영역 등록.
2. 현재 탑뷰를 기본 이미지로 선택하고 현장 설정 저장 → 현장 백업 저장.
3. 웍스 하루치 가져오기 시험 → 샘플 원문으로 배치 시험 → 위치 확인 → 일괄 반영.
4. 실제 수집은 같은 메뉴의 로그인 창 열기 → 직접 로그인 → 캘린더 하나/하루 보기 → 하루치 읽기 → 확인 후 반영.

이번 기본 흐름에는 개별 일정 클릭과 JSON 저장이 필요 없습니다. 기존 독립 시험기는 진단용으로 남겼습니다.

## 추가·변경

- 동·시설 기본 설정을 회의와 분리해 저장. 이미지 포함 백업/복원, 최근 5개 설정 자동 보관.
- Windows 실행기는 `%LOCALAPPDATA%/MouseOn`에 데이터를 보관해 프로그램 폴더 교체 후 재사용.
- 일정의 동·시설 이름을 규칙으로 찾아 배치. 불명확한 위치는 지도에 찍지 않고 확인 대기.
- 기존 수집 키 중복 방지와 수동 위치 보존.
- 제목 좌우 날짜 이동, 요일 표시, 일요일 제외. 금요일 토·일 묶음 제거.
- 참여자별 그림/포인터 색상과 중복 이름 구분.
- 메뉴 도킹, 화면 채우기, 간단한 작업명, 그리기 중 지우기.
- 작업 종류별 색상, 동선과 하역 위치 동시 등록, ! 이유 hover.

## 검증과 한계

자동 테스트 **22개 통과**, production ZIP 시작·인증·저장 모듈과 무결성 검사 통과.
실제 Windows, 회사 계정의 웍스 DOM, 회사망/LTE 연결은 아직 검증 전입니다.
수집은 현재 화면에 로드된 일정 요소만 읽습니다. 실제 화면이 맞지 않으면 오류로 멈춥니다.
전체 누락 없는 수집·주기적 동기화·원본 수정/취소 반영·AI 의미 해석·PMX·자동 간섭 판정은 아직 미구현입니다.
위치와 작업 분류는 규칙 기반 시험으로 표시하며 북측 방향 등은 임의로 추정하지 않습니다.

로그인 프로필은 해당 PC에만 보관하고 ZIP에는 사용자 사진/일정/로그인 정보를 포함하지 않았습니다.
기존 데이터 폴더는 보관하고, 사용 순서와 저장 위치는 ZIP 안 `QUICKSTART.txt`를 확인하세요.

## 모바일 상단 도구와 구간 확대 업데이트

- 모바일은 세로 화면을 기본으로 도구를 상단에 배치하고 가로 회전 후에도 유지합니다.
- 펜 버튼을 다시 누르거나 종료하면 그리기를 해제합니다. 지우기는 공유 그림 삭제와 함께 누른 사람의 그리기를 해제합니다.
- PC 회의 도구의 구간 확대에서 사각형을 드래그하면 해당 부분을 중심 확대합니다.
- 이전 보기로 직전 확대/이동 상태를 복원하고 전체 보기로 사진 전체를 맞춥니다. Esc로 구간 선택을 취소할 수 있습니다.
- 기존 실행 창을 닫고 새 ZIP을 압축 해제해 실행하세요. 같은 계정의 영구 데이터 폴더를 유지합니다.
