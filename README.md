# MouseOn r046 — 색상 배경 작업 아이콘

MouseOn r046 — 색상 배경 작업 아이콘
r039~r045에서 바로 적용

패치 로그
- 선택하신 혼합안을 적용했습니다. 장비별 단색 배경을 사용하고, 배경의 상대 휘도로 검정/흰색 심볼 중 더 높은 명암 대비를 자동 선택합니다.
- 굴착기 오렌지, 스카이 보라, 크레인 적색, 펌프카 청색, 롤러 노랑, 지게차 녹색 등 장비를 구분합니다. 사용자 지정 고위험 색상은 보존하고 대비를 자동 조정합니다.
- 선택 외곽선과 설명창의 밝은 배경/진한 글씨를 유지합니다. 사진·상하 경고·차량 동선은 각 의미를 유지합니다.
- r045 사진 위치 이동, 경고 숨김/복원, 위치 해제, 갤럭시 화면 개선 및 기존 기능 포함.
- PMX 실시간 연동과 신규 반경 도구는 이번 버전 미포함입니다. PMX판은 별도 준비합니다.

적용 방법
1. 검은 실행창과 연동 엣지를 종료합니다.
2. ZIP의 MouseOn 폴더 내용을 기존 r039~r045 폴더에 병합·덮어씁니다. data 폴더는 유지하세요.
3. Start-MouseOn-Internet.bat 재실행 후 PC Ctrl+F5, 모바일 새로고침.
4. 현장 계정에 다시 로그인합니다. SQL 변경은 없습니다.

검증: 장비/사용자 지정 색상별 대비 및 PC·모바일 다크 선호 화면과 조작 검증. r039~r045 병합 결과와 전체 ZIP 일치 확인.
