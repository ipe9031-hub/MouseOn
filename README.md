# MouseOn r023 — 모바일 아이콘 그리기 · 내 그림 지우기

- r022 사용자는 `MouseOn-Patch-r022-to-r023.zip` 소형 패치를 받으세요.
- r008~r022(0b33141 이후)은 `MouseOn-Patch-r023.zip` 누적 패치를 사용하세요.
- 신규 사용자는 `MouseOn-Full-r023.zip`을 사용하세요. 이전 ZIP은 보관본입니다.

실행 창과 웍스 연동 창을 닫고 폴더를 백업한 뒤 패치 안 MouseOn 내용물을 기존 MouseOn 안에 병합·덮어쓰세요.
재실행 후 PC Ctrl+F5, 모바일은 기존 탭을 닫고 새 QR로 참여해주세요. 기존 사진·영역·현장 정보는 유지합니다.

## 이번 변경

- 모바일의 주변 그리기 메뉴는 글자 없이 아이콘만 표시합니다. 아이콘 이름은 접근성 이름·툴팁으로 유지합니다.
- 지우개 아이콘은 본인이 그린 선을 한 번에 지웁니다. 다른 사람의 선은 보존하고 그리기 모드는 유지합니다. 주최자 PC의 전체 지우기 권한은 그대로입니다.
- 같은 브라우저 탭에서는 새로고침·재접속 후에도 본인 선을 구분합니다. 이름이 같거나 클라이언트가 다른 사람의 구분 값을 보내도 다른 사람의 그림을 지우지 않습니다.
- **본인 구분 정보가 없는 이전 버전 그림은 임의로 지우지 않습니다. 본인 지우기는 r023 이후 새로 그린 선부터 적용됩니다.** 브라우저·기기·접속 주소를 바꾸면 본인 구분 정보는 이어지지 않습니다.
- 도구가 바뀌면 기존 입력을 종료합니다. 이미 그린 선은 유지합니다. 그리기 중 짧게 누르면 펜 대신 취소 아이콘을 표시하고 취소하면 그리기를 종료합니다.
- 현장 사진·아이콘에서 기본 복사 메뉴, 파란 텍스트 선택과 이미지 드래그를 막습니다. 입력칸과 공유 링크의 선택·복사는 유지합니다.

자동 테스트 63개 통과. 본인 선만 지우기·다른 참여자 선 보존·새로고침 후 본인 구분·같은 브라우저의 탭 구분·소유 정보 위조 무시·툴 변경 시 입력 종료·짧은 탭 취소 및 기본 선택 방지를 검증했습니다.
브라우저 기본 복사 메뉴 차단은 iPhone 실제 단말에서도 최종 확인해주세요.
누적 패치는 기존 14개 배포본에 적용한 파일이 전체 배포본과 일치함을 검증했습니다.
웍스 의미 해석은 이번 변경에 포함하지 않았습니다. 추가 원칙은 DESIGN.md에도 기록했습니다.

# MouseOn r021 — PC·모바일 공통 화면과 직접 편집

- r020 사용자는 `MouseOn-Patch-r020-to-r021.zip` 소형 패치를 받으세요.
- r008~r020(0b33141 이후)은 `MouseOn-Patch-r021.zip` 누적 패치를 사용하세요.
- 신규 사용자는 `MouseOn-Full-r021.zip`을 사용하세요. 이전 리비전 ZIP은 보관본입니다.

실행 창과 웍스 연동 창을 닫고 기존 폴더를 백업하세요. 패치 안 MouseOn 내용물을 기존 MouseOn 안에 병합·덮어씁니다.
재실행 후 PC Ctrl+F5, 모바일 새로고침을 해주세요. iPhone은 참여 페이지를 닫고 링크를 다시 열어 새 화면 설정을 적용하세요.
사진·영역·현장 설정·data는 유지합니다.

## 화면 원칙

- 클릭·터치 위치 근처에 상황에 맞는 완료·취소·삭제를 제공합니다.
- PC·모바일은 같은 디자인·아이콘·메뉴 구조를 사용합니다. 기기별 차이는 사용자가 요청한 경우에 적용합니다.
- 명일 작업사항 제목과 날짜 이동은 두 기기에 항상 표시합니다.
- 주변에 뜨는 이름 입력창·도구 메뉴는 ⠿ 손잡이를 끌어서 옮깁니다. 버튼 클릭·이름 입력과 구분하며 화면 밖으로 벗어나지 않게 제한합니다.

## 이번 변경

- 공통 도구를 펜 → 작업 등록 → 사진 추가 → QR 공유로 통합하고 기본 표시합니다. 회의 도구(…)는 제거했습니다.
- 작업 순서와 위치 확인 대기는 작업 등록 안 작업 관리에 모았습니다. 사진 추가·QR은 PC와 모바일 모두 가능합니다.
- 배율 도구도 공통으로 표시하며 100%를 누르면 전체 사진으로 맞춥니다. 명일 작업사항 제목은 작은 화면에서도 숨기지 않습니다.
- 모바일 입력창의 브라우저 자동 확대를 방지하고 보이는 브라우저 영역 크기에 앱 틀을 맞춥니다. 사진만 별도로 확대·이동합니다.
- 모바일 작업 아이콘을 20% 더 줄였습니다. 탭은 작업 확인, 0.4초 길게 누른 뒤 끌기는 위치 이동입니다. 이동 버튼은 숨기고 삭제는 하단에 표시합니다.
- 시스템 메시지는 공통 글씨 알림으로 잠깐 표시합니다. 알림·삭제·배율 도구가 겹치지 않게 배치했습니다.
- 영역 점 추가는 경계선 위를 정확히 누를 필요 없이 누른 위치 자체에 새 점을 배치합니다. 외곽선 밖은 경계로 붙입니다.
- 점 이동 시 수치상 중복 점을 정리하고, 경계 정리 결과가 잘못되면 검증된 원래 다각형 결과를 사용합니다. 이동 중 일시적인 잘못된 모양은 경고를 반복하지 않으며, 손을 놓은 마지막 위치가 유효하지 않을 때 구체적인 원인을 표시합니다.

## 검증

전체 자동 테스트 59개 통과. 터치 이벤트로 그린 선의 다른 화면 공유, 모바일 길게 눌러 이동, 탭 확인, 하단 삭제, QR·사진 선택, 세로·가로 도구 및 제목 표시를 검증했습니다.
원하는 위치에 점 추가, 가까운 중복 점 정리와 메뉴 손잡이 이동도 검증했습니다. iPhone 실제 단말에서 보고된 자동 확대·잘림 수정은 사용자 단말에서 최종 확인이 필요합니다.
누적 패치는 기존 12개 배포본에 적용한 파일이 전체 배포본과 일치함을 검증했습니다.
웍스 분류별 배치·여러 동과 ‘사이’ 의미 해석은 후속 개발이며 이번 변경에는 포함하지 않았습니다.

재실행 후 PC Ctrl+F5, 모바일 새로고침을 해주세요. 현장 설정·사진과 data 폴더는 유지합니다.

# MouseOn r017 — 외곽선 자동 맞춤과 영역 빼기

- 최신 r016 사용자는 `MouseOn-Patch-r016-to-r017.zip` 소형 패치를 사용하세요.
- r008~r016(0b33141 이후) 사용자는 `MouseOn-Patch-r017.zip` 누적 패치를 사용하세요.
- 처음 사용하면 `MouseOn-Full-r017.zip`을 사용하세요. 아래의 리비전 없는 ZIP은 이전 r016입니다.

실행 창과 웍스 연동 창을 닫고 기존 폴더를 백업한 뒤 패치 안 MouseOn 내용물을 기존 폴더에 병합·덮어씁니다.
다시 실행하고 PC Ctrl+F5, 모바일 새로고침을 해주세요. data 폴더는 삭제하지 마세요.

건물 영역은 세 번째 점부터 누른 곳 가까이에 이름·완성 입력창이 나타납니다. 점을 더 찍어 모양을 계속 만들 수 있고 완성하면 입력한 이름으로 독립 영역이 생성됩니다.

r017에서는 영역을 그릴 때 외곽선 밖의 점을 가장 가까운 외곽선으로 붙이고 가까운 안쪽 점도 경계에 맞춥니다.
내부 경계 점을 밖으로 끌 때도 외곽선으로 붙입니다. 기존 외곽선 모서리는 전체 경계를 보존하도록 유지합니다.
완성한 건물 영역은 오목한 현장 외곽선으로 잘라내며 겹친 부분은 새 영역이 차지하고 이웃의 나머지 모양·이름은 유지합니다.
설정 사진은 메인 화면처럼 화면을 채우고 안내는 배경 없는 글씨로 3.5초 뒤 사라집니다.
선택 영역 빼기(−)를 추가했으며 이웃이 빈 공간을 채웁니다. 영역 최대 100개, 새 외곽선·건물 그리기 최대 160점입니다.

전체 자동 테스트 50개 통과 후 설정 화면·알림 변경 관련 테스트와 160점 저장 검증을 추가로 통과했습니다. 누적 패치는 기존 여덟 배포본에 덮어쓴 파일 내용이 전체 배포본과 일치함을 확인했습니다.
웍스 캘린더 분류별 배치 제외·여러 동 의미 해석은 후속 개발 사항이며 이번 패치에는 포함하지 않았습니다.

# MouseOn 영역 설정·모바일 조작 수정 시험판

Windows 10/11 x64용입니다. 최근 a95d9b5 버전을 사용했다면 `MouseOn-Patch-from-a95d9b5.zip`을 받으세요.
이전 버전이거나 잘 모르겠으면 `MouseOn-Patch-from-0b33141.zip` 누적 패치 또는 전체 `MouseOn-Internet-Windows-x64.zip`을 사용하세요.
`MouseOn-Design-Patch-from-a5c6b3d.zip`도 이번 내용까지 갱신했습니다.

실행 창과 웍스 연동 브라우저를 닫고 기존 폴더를 백업하세요. 패치 ZIP 안 MouseOn의 내용물을 기존 MouseOn 폴더 안에 병합·덮어쓴 뒤 다시 실행합니다.
PC는 Ctrl+F5, 모바일은 새로고침하세요. 기존 data 폴더와 %LOCALAPPDATA%/MouseOn은 삭제하지 마세요.
처음 사용하는 경우 전체 ZIP을 풀고 Start-MouseOn-Internet.bat을 실행합니다.

## 이번 변경

- 사진 위에 뜨는 도구로 외곽선 점을 추가·삭제·이동합니다. 사진 크기는 그대로입니다.
- 점으로 별도 건물 영역을 그려 완성하면 주변 영역이 공간을 내줍니다. 건물 영역은 자동 영역 추가 후에도 유지합니다.
- 영역을 누른 곳 가까이 이름 입력창이 뜨며 이름과 모양을 함께 수정합니다. 현장 설정의 제목은 ‘영역’입니다.
- 사진을 짧게 누르면 그리기·작업 등록을 고릅니다. 작업은 누른 위치에 기본 등록하고 영역·동선은 필요할 때 지정합니다.
- 작업 저장·취소 후 지도 화면으로 돌아갑니다. 작업 설명이 세로 한 글자씩 꺾이던 문제를 수정했습니다.
- 모바일은 100%에서 사진 위치를 고정합니다. 확대했을 때 사진 범위 안에서 이동하며 인터페이스 크기는 유지합니다.
- 현장 설정은 오른쪽 위 스프로킷 아이콘 하나로 표시하고 웍스 가져오기를 그 안으로 옮겼습니다.
- 메인 화면의 이전 보기·전체 보기 버튼을 제거했습니다. 주최자 PC에서 기존 그림이 있을 때 펜으로 짧게 누르면 주변 메뉴에 지우기가 표시됩니다.
- QR 아이콘 모양 교체와 전체 회의 도구(…) 제거는 이번 변경에 포함하지 않았습니다.
